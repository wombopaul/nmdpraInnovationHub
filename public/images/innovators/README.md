# Innovator Images

This directory contains profile photos for the NMDPRA Innovators Hall of Fame.

## Image Requirements:
- **Format**: JPG, PNG, or WebP
- **Size**: 400x400 pixels (square aspect ratio)
- **File Size**: Maximum 500KB per image
- **Quality**: High resolution for professional presentation

## Fallback Behavior:
If an image file is not found or fails to load, the system will automatically display a colored circular avatar with the person's initials as a fallback.

## Adding New Innovators:
1. Add the profile image to this directory following the naming convention: `firstname-lastname.jpg`
2. Update the corresponding section in the Hall of Fame to reference the new image
3. Ensure the image meets the size and quality requirements listed above
